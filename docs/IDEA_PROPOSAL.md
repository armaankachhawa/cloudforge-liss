# CloudForge-LISS — Idea Submission Draft

## Title

**CloudForge-LISS: Evidence-guided, uncertainty-aware cloud reconstruction for analysis-ready LISS-IV imagery**

## One-line pitch

CloudForge-LISS reconstructs only cloud- and cloud-shadow-contaminated LISS-IV pixels using mask-aware generative learning, preserves every valid observation exactly, and supplies a confidence layer so downstream GIS users can distinguish measurement from estimation.

## Problem and user need

Persistent clouds over Northeast India create large temporal gaps in high-resolution optical observations. Conventional masking identifies unusable pixels but leaves holes in land-cover, flood, environmental and infrastructure products. Pure image-generation systems can fill those holes visually yet introduce false roads, field boundaries or spectral values. Operational users therefore need reconstruction that is spatially plausible, spectrally consistent, georeferenced and explicit about uncertainty.

## Proposed solution

The system is deliberately staged.

1. A small three-class U-Net identifies clear surface, cloud and cloud shadow.
2. The core five-channel Attention ResUNet receives LISS-IV bands plus cloud and shadow masks.
3. Training pairs are generated by corrupting real clear LISS-IV patches with cloud texture and shadow patterns sampled from real cloudy LISS-IV scenes.
4. A weighted masked loss combines L1 accuracy, SSIM structure, spectral-angle consistency and edge continuity.
5. At inference, overlapping tiles are blended and only contaminated pixels are replaced. Clear source pixels remain bit-identical.
6. A confidence raster combines distance from visible evidence, connected cloud-region size and test-time augmentation disagreement.
7. Enhanced mode optionally adds aligned Sentinel-1 VV/VH and temporal LISS-IV observations when they are available.

## Innovation

- **Measurement-preserving composition:** AI never modifies observed clear pixels.
- **Sensor-native supervision:** training uses multi-band raster values and real LISS cloud texture, not RGB screenshots or white synthetic shapes.
- **Uncertainty as a product:** every reconstruction is accompanied by a spatial confidence layer and provenance metadata.
- **Operational fallback:** the core mode works with LISS-IV alone; auxiliary SAR/temporal imagery improves confidence without becoming mandatory.
- **Leakage-resistant validation:** train, validation and test are divided by scene/date/AOI, and metrics are calculated only in hidden regions.
- **Analysis-ready outputs:** reconstructed image, mask and confidence are GeoTIFFs retaining CRS, affine transform, dimensions, band order and nodata metadata.

## Technical architecture

Cloudy LISS-IV
      │
      ├──► Cloud Mask U-Net ──► cloud + shadow labels

                                     ▼

              ▼                      ▼                      ▼

Enhanced mode adds Sentinel-1 VV/VH and an optional temporal LISS-IV reference as explicitly aligned auxiliary channels.

## Dataset plan

The initial study covers three terrain regimes:

- Assam floodplain: rivers, seasonal water, cropland and settlements.
- Meghalaya hills: relief shadows, dense forest and persistent clouds.
- Tripura/Manipur/Nagaland: mixed agriculture, vegetation and small settlements.

MVP target: 12–20 clear scenes, 8–12 cloudy scenes, at least three AOIs, 20–30 real cloud-mask sources, 3,000–8,000 patches and 3–5 geographically independent test scenes. Product metadata, units and delivered band order will be audited before training.

## Evaluation

Synthetic-cloud test scenes provide known ground truth. PSNR, SSIM, MAE, RMSE and Spectral Angle Mapper are evaluated only inside cloud/shadow masks. Red/NIR products additionally receive NDVI-error analysis. Real cloudy scenes are assessed through cloud residue, spectral outliers, edge continuity and expert visual inspection of rivers, roads, field boundaries and forest texture.

The no-AI baseline blanks masked pixels. Model 1 is the LISS-only Attention ResUNet. Model 2 is auxiliary fusion. All comparisons use the same scene-held-out split.

## Deliverables

- Automated mask and reconstruction pipeline
- Analysis-ready reconstructed LISS-IV GeoTIFF
- Cloud/shadow and confidence GeoTIFFs
- Before/after preview and machine-readable quality report
- Reproducible training/evaluation code
- Streamlit demonstration
- Comparative baseline/core/auxiliary assessment

## Responsible-use statement

Reconstructed pixels are estimates, not new observations. Large opaque regions receive reduced confidence. The system will not claim guaranteed recovery beneath clouds and will expose its reconstruction mask, confidence and processing provenance to downstream users.
